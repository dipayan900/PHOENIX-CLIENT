# PHOENIX CLIENT 🔥

**Rise from the ashes. Rule the game.**

Phoenix Client is an Android-first Minecraft Java launcher project with an original fire-themed identity. This repository currently establishes the Android application shell, responsive Compose dashboard, local profile prototype, build pipeline, and the integration boundary for a compatible Minecraft Java runtime.

## Current implementation status

- [x] Native Android application project (Kotlin + Jetpack Compose)
- [x] Original Phoenix dark/fire visual system
- [x] Dashboard and in-app navigation
- [x] Local offline profile prototype (launcher profile only; not Mojang/Microsoft authentication)
- [x] Version/profile settings UI foundation
- [x] GitHub Actions debug APK workflow
- [ ] Minecraft Java runtime integration and actual game launch
- [ ] Microsoft account OAuth/device-code flow
- [ ] Version metadata/download/install pipeline
- [ ] Fabric/Forge integration
- [ ] In-game HUD and touch controls
- [ ] Cosmetic rendering integration

**Important:** The current app is a launcher foundation, not yet a playable Minecraft launcher. The Play action deliberately reports that the runtime integration is not installed rather than pretending to launch a game. A compatible PojavLauncher-derived runtime integration must be separately evaluated, licensed, ported and tested on target Android devices. Minecraft assets/accounts must be supplied and used under their applicable terms.

## Build

Open the repository's **Actions** tab and run **Build Phoenix Client APK**, or push to the main branch. The workflow uploads a debug APK artifact.

Requirements for local builds: JDK 17, Android SDK 35, Gradle 8.9 (wrapper is generated by CI).

## Architecture

- `app/`: Android application.
- `app/src/main/java/com/phoenix/client/`: Compose UI and app entry point.
- `.github/workflows/`: cloud APK build.
